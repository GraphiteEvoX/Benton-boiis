BENTON BOYS DISPATCH MANAGER — iPhone version

This is a mobile-friendly web app/PWA. It stores jobs on the device/browser using local storage and includes backup/restore.

To use it as an installable iPhone web app, the files need to be hosted at an HTTPS web address. Once hosted, open that address in Safari and use Share > Add to Home Screen.

The app itself is fully contained in index.html. No server is required for local use, but cloud sync/login requires a backend, which is not included in this local version.
